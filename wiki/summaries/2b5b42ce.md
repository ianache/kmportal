# Commit 2b5b42ce

        **fix(api): rename mcp package to mcp_server to avoid naming conflict with fastmcp dependency

FastMCP internally imports from 'mcp' package, which conflicts with our
local 'mcp' directory. This caused ImportError: cannot import name 'McpError'
from partially initialized module 'mcp'.

Renamed api/src/mcp/ to api/src/mcp_server/ and updated all imports.

The API now starts successfully and serves requests on port 8000.**

        Renames the local `api/src/mcp` package to `api/src/mcp_server` to resolve a naming conflict with the `fastmcp` dependency, fixing import errors and ensuring the API starts successfully.

        - `api/src/main.py`

        ## Entities
        - **mcp_server** (module): The new name for the Model Context Protocol (MCP) module located at `api/src/mcp_server`, which provides server functionality for AI Agent Integration.
- **get_mcp_app** (function): A function within the `mcp_server` module that returns the ASGI application instance for the MCP server.
- **MCPAuthMiddleware** (class): An authentication middleware for MCP endpoints that validates API keys provided in the `X-API-Key` header.
- **require_scope** (function): A utility function that checks if an authenticated API key has the necessary scope to access a specific MCP resource.
- **check_domain_access** (function): A utility function that verifies if an authenticated API key is authorized to access a specific knowledge domain.

- **FastMCP** (concept): A third-party dependency (package) used to implement the Model Context Protocol, whose internal 'mcp' package name caused a conflict.
- **APIKeyService** (class): A service responsible for validating API keys, utilized by `MCPAuthMiddleware` to authenticate requests.
- **mcp** (module): The former name of the Model Context Protocol module that caused a naming conflict with the 'FastMCP' dependency.
