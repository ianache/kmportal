# Commit 06f74899

        **fix(api): add missing embed_document and embed_query methods to OllamaAdapter**

        This commit adds missing `embed_document` and `embed_query` methods to the `OllamaAdapter` for specialized embedding tasks, introduces new utility scripts for database and embedding adapter testing, and documents several key architectural concepts in the project wiki.

        ## Changed Files
        - `api/check_db.py`
- `api/src/adapters/embedding/ollama.py`
- `api/test_embedding.py`

        ## Entities
        - **OllamaAdapter** (class): An implementation of the `EmbeddingPort` interface, utilizing a local Ollama instance to generate text embeddings.
- **embed_document** (function): A new method in `OllamaAdapter` designed to generate an embedding optimized for documents. It calls the general `embed` method and returns the first embedding vector from the result.
- **embed_query** (function): A new method in `OllamaAdapter` designed to generate an embedding optimized for search queries. It calls the general `embed` method with the input text wrapped in a list and returns the full `List[List[float]]` result, despite its type hint `List[float]`.
- **EmbeddingPort** (class): An interface defining the contract for embedding adapters, which `OllamaAdapter` implements, requiring methods for general, document, and query specific embeddings.
- **api/src/adapters/embedding/ollama.py** (module): The module containing the `OllamaAdapter` class and its methods for interacting with the Ollama embedding API.
- **api/check_db.py** (module): A new utility script providing asynchronous functions to check database connectivity, list documents, domains, and all public tables.
- **check** (function): An asynchronous function within `api/check_db.py` that performs database inspection by querying for documents, a specific domain, and listing all public tables.
- **api/test_embedding.py** (module): A new utility script for verifying the functionality of the configured embedding adapter by generating a sample embedding.
- **test** (function): An asynchronous function within `api/test_embedding.py` that initializes an embedding adapter, retrieves its details, and attempts to embed a sample text.
- **ARCHITECTURE.md** (concept): A project wiki concept document detailing the current architectural research, decisions, and baseline for the project.
- **CanvasToolbox** (concept): A project wiki concept documenting an architectural decision regarding a UI component for canvas tools, to be kept within `domains-ui` for v1.1.
- **Embedding Factory** (concept): A project wiki concept describing the system logic responsible for creating and providing the appropriate embedding adapter based on configuration.
- **Hash-based Embeddings** (concept): A project wiki concept outlining a fallback strategy for embedding generation that creates embeddings based on content hashing when API-based models are unavailable.
- **Ollama Embedding** (concept): A project wiki concept related to the integration and use of Ollama for generating embeddings within the system.
