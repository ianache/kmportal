# Commit b9b3d430

        **feat(api): Phase 9 - FastMCP Server for AI Agent Integration

Plan 09-01: FastMCP Server for AI Agent Integration
- Add MCP module with FastMCP server instance
- Create MCP tools for AI agents:
  - search_knowledge: Search documents (semantic, keyword, hybrid)
  - list_domains: List all knowledge domains
  - get_domain_info: Get detailed domain information
  - get_document_status: Check document ingestion status
- Add API key authentication middleware (MCPAuthMiddleware)
  - Validates X-API-Key header
  - Attaches scopes and domain restrictions to request state
- Mount MCP as ASGI sub-app at /mcp following Decision D002
- MCP endpoints:
  - GET /mcp/sse - SSE endpoint for real-time communication
  - POST /mcp/messages - Message endpoint for tool calls

Authentication:
- Requires X-API-Key header for all MCP requests
- API keys validated against database
- Scopes control access level (read, write, admin)
- Domain restrictions supported via API key configuration

Integration:
- Uses existing SearchService, DomainService, IngestionService
- Leverages AsyncSessionLocal for database sessions
- FastMCP already in dependencies (fastmcp>=0.4.0)**

        This commit introduces the FastMCP Server for AI Agent Integration, including new MCP tools for knowledge base interaction, API key authentication middleware, and mounts the MCP as an ASGI sub-app.

        ## Entities
        - **mcp** (module): New Python module that encapsulates the Model Context Protocol (MCP) server and its related components for AI Agent Integration.
- **FastMCP Server** (concept): An instance of the FastMCP framework serving as the Model Context Protocol server, specifically designed for AI agents to interact with the knowledge base.
- **AI Agent Integration** (concept): A new system capability allowing external Artificial Intelligence agents to programmatically access and interact with the knowledge base via the MCP.
- **MCP Tools** (concept): A conceptual category encompassing the functions and capabilities exposed by the FastMCP server, such as searching knowledge, listing domains, and checking document statuses.
- **get_mcp_app** (function): A factory function located in the `mcp.server` module that constructs and returns the ASGI application instance for the FastMCP server.
- **MCPAuthMiddleware** (class): A Starlette/FastAPI middleware that intercepts incoming MCP requests, validates API keys from the `X-API-Key` header, and populates `request.state` with authentication details (scopes, allowed domains).
- **require_scope** (function): An asynchronous dependency function intended for use with FastAPI endpoints, which enforces that the authenticated API key possesses a specific permission scope.
- **check_domain_access** (function): An asynchronous dependency function used in FastAPI endpoints to ensure the authenticated API key is permitted to access a given knowledge domain, based on configured domain restrictions.
- **X-API-Key Header** (concept): The custom HTTP header (`X-API-Key`) required for authenticating requests to the MCP server, containing the client's unique API key.
- **Scopes** (concept): Permission identifiers (e.g., 'read', 'write', 'admin') associated with an API key, dictating the operational privileges an AI agent holds within the MCP system.
- **Domain Restrictions** (concept): A security mechanism applied to API keys, limiting the API key's access to a predefined set of knowledge domains within the system.
- **api/src/main.py** (module): The primary application file for the Knowledge Management Center API, updated to include the mounting of the new FastMCP server as a sub-application at `/mcp`.
- **api/src/mcp/__init__.py** (module): The package initialization file for the `mcp` module, defining what symbols are publicly accessible when the package is imported.
- **api/src/mcp/auth.py** (module): A new module dedicated to handling API key-based authentication for the MCP server, containing the `MCPAuthMiddleware` and related helper functions.
- **api/src/mcp/server.py** (module): A new module housing the core logic for the FastMCP server, including its definition, endpoints, and the implementation of MCP tools.
- **/mcp/sse** (endpoint): The Server-Sent Events (SSE) endpoint provided by the FastMCP server, used for real-time, unidirectional communication from the server to connected AI agents.
- **/mcp/messages** (endpoint): The message POST endpoint of the FastMCP server, designed for AI agents to send structured requests, often invoking specific MCP tools or operations.
- **search_knowledge** (tool): An MCP tool that allows AI agents to query the knowledge base using various search methodologies (semantic, keyword, hybrid).
- **list_domains** (tool): An MCP tool that enables AI agents to retrieve a list of all accessible knowledge domains.
- **get_domain_info** (tool): An MCP tool that provides AI agents with detailed metadata and configuration for a specified knowledge domain.
- **get_document_status** (tool): An MCP tool that allows AI agents to inquire about the ingestion and processing status of specific documents within the knowledge base.
