        ## Entities
        - **Frontend Shell** (module): The main host application for the frontend, built with Vue 3 and Module Federation, providing global layout, authentication, and a design system for integrating micro-UIs.
- **Pinia auth store** (module): A Pinia store at `src/stores/auth.ts` managing user session, login/logout actions, and role-based access (isAdmin, isReader).
- **BFF API client** (module): An HTTP client at `src/services/bffClient.ts` for proxying requests to the Core API via the BFF, including 401 error handling.
- **Vue Router** (module): The application's routing system configured at `src/router/index.ts` with auth guards for public, protected, and admin-only routes.
- **AuthCallback view** (class): A Vue view component at `src/views/AuthCallback.vue` dedicated to handling OAuth2 callbacks.
- **LoginRequired view** (class): A Vue view component at `src/views/LoginRequired.vue` prompting users to log in when authentication is required.
- **ShellLayout component** (class): A global layout component at `src/components/layout/ShellLayout.vue` featuring a glassmorphism sidebar, responsive design, user info, and logout functionality.
- **Design tokens CSS** (module): A CSS file at `src/styles/design-tokens.css` defining global design variables for colors (Luminous Knowledge), typography (Inter font), spacing, border radius, glassmorphism, shadows, and utility classes.
- **BaseButton component** (class): A reusable UI component at `src/components/ui/BaseButton.vue` supporting primary, secondary, tertiary, and danger variants.
- **BaseCard component** (class): A reusable UI component at `src/components/ui/BaseCard.vue` providing card containers with low, medium, and high elevation styles.
- **BaseInput component** (class): A reusable UI component at `src/components/ui/BaseInput.vue` for text input fields, including support for icons and validation.
- **ToastContainer component** (class): A reusable UI component at `src/components/ui/ToastContainer.vue` that implements a notification system.
- **useBreakpoint composable** (function): A Vue composable at `useBreakpoint.ts` used for detecting responsive breakpoints (mobile, tablet, desktop).
- **Module Federation** (concept): A webpack feature utilized to allow the Frontend Shell to host and dynamically load remote micro-frontends and share dependencies as singletons.
- **Luminous Knowledge design system** (concept): The defined design system whose principles and components are implemented in the Frontend Shell, including design tokens and UI components.
- **adminUi micro-UI** (module): One of the micro-frontend applications updated to be a Module Federation remote and use singleton dependencies shared from the host shell.
- **domainsUi micro-UI** (module): One of the micro-frontend applications updated to be a Module Federation remote and use singleton dependencies shared from the host shell.
- **ingestionUi micro-UI** (module): One of the micro-frontend applications updated to be a Module Federation remote and use singleton dependencies shared from the host shell.
