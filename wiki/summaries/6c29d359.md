# Commit 6c29d359

        **fix(api): resolve module import issues with proper package structure

- Add missing __init__.py files to src/ and src/core/ directories
- Update start scripts to use --app-dir src flag (proper uvicorn approach)
- Add README with clear instructions on how to run the API

The --app-dir flag tells uvicorn to look for modules in the src directory,
resolving the 'ModuleNotFoundError: No module named db' error.

Usage options:
1. uv run dev (uses uv scripts from pyproject.toml)
2. start.bat or ./start.sh (updated scripts)
3. uvicorn main:app --app-dir src --reload (direct with --app-dir)
4. python start.py (Python module approach)**

        This commit resolves API module import issues by adding missing __init__.py files, updating start scripts and the README to consistently use the uvicorn --app-dir src flag, and providing clear quick start instructions.
