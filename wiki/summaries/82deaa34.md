        ## Entities
        - **Frontend Shell Phase 6** (concept): The Module Federation host application that manages authentication, global layout, and integrates micro-UIs.
- **06-01-PLAN.md** (decision): A detailed plan for implementing authentication state management and BFF integration in the Frontend Shell.
- **06-02-PLAN.md** (decision): A detailed plan for implementing the Luminous Knowledge Design System and global layout in the Frontend Shell.
- **06-03-PLAN.md** (decision): A detailed plan for integrating Module Federation in the Frontend Shell, including singleton verification and remote loading.
- **Auth State Management** (concept): The system responsible for handling user authentication, session validation, login/logout flows, and providing reactive user data in the Frontend Shell.
- **Design System** (concept): The set of design tokens, components, and guidelines (Luminous Knowledge) for consistent UI across the frontend.
- **Module Federation Integration** (concept): The process of setting up Module Federation for the Frontend Shell to host and consume micro-UIs, ensuring shared dependencies.
- **Pinia** (module): A state management library for Vue.js, specified for use in the authentication store within the Frontend Shell.
- **Vue Router** (module): The official router for Vue.js, specified for use with navigation guards in the Frontend Shell.
- **BFF** (module): The Backend For Frontend layer, responsible for OAuth2 proxy, API forwarding, and session management, integrated with the Frontend Shell.
- **Keycloak** (concept): The identity and access management solution used for authentication, proxied by the BFF.
- **frontend/apps/shell/src/stores/auth.ts** (module): The Pinia store module managing authentication state in the Frontend Shell, providing user state and login/logout actions.
- **frontend/apps/shell/src/middleware/auth.ts** (module): Vue Router navigation guards for enforcing authentication rules and redirects in the Frontend Shell.
- **frontend/apps/shell/src/services/bffClient.ts** (module): A client module for interacting with the BFF API, specifically for authentication-related requests and session cookie handling.
- **frontend/apps/shell/src/types/auth.ts** (module): TypeScript type definitions for authentication-related data structures used across the Frontend Shell.
