# Commit 481f0564

        **fix(api): set PYTHONPATH in Dockerfile to fix module imports

Add PYTHONPATH=/app/src environment variable to ensure Python can find
the local modules (db, api, mcp, core) when running uvicorn.

This fixes the ModuleNotFoundError: No module named 'db' error that
occurs when the container starts.**

        This commit resolves a ModuleNotFoundError in the API Docker container by setting the PYTHONPATH environment variable to /app/src within the api/Dockerfile, allowing uvicorn to correctly find local Python modules.
