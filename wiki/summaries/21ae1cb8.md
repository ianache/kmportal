        **fix(api): clean up pyproject.toml and add comprehensive README

- Remove deprecated [tool.uv.scripts] section (uv doesn't support this format)
- Remove duplicate dev-dependencies sections
- Move dev dependencies to [project.optional-dependencies]
- Add comprehensive README with clear CORRECT vs INCORRECT examples
- Explain why --app-dir src is required for imports to work

The key insight is that the code uses absolute imports (from db.database import ...)
which requires uvicorn to be run with --app-dir src flag so that 'src' becomes
the package root, not 'src.main'.

Usage:
  ✅ python start.py
  ✅ uvicorn main:app --app-dir src --reload
  ❌ uvicorn src.main:app --reload  # WRONG!**

        This commit cleans up `pyproject.toml` by removing deprecated `uv` configurations and reorganizes dev dependencies, while extensively updating `README.md` to clarify correct API execution methods using `--app-dir src` to resolve absolute import issues.
