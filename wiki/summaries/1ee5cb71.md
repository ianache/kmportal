# Commit 1ee5cb71

        **fix(domains-ui): correct store method name in onMounted hook

Change store.loadDomains() to store.fetchDomains() to match the actual
method name exported by the domains store. This fixes the runtime error:
'Uncaught TypeError: store.loadDomains is not a function'

The store exports 'fetchDomains' but the component was calling the
non-existent 'loadDomains' method.**

        This commit fixes a runtime error in the domains-ui application by changing the store method call from `store.loadDomains()` to `store.fetchDomains()` in the `onMounted` hook of `App.vue`.

        - `frontend/apps/domains-ui/src/App.vue`
