        ## Entities
        - **Phase 7: Core micro UIs** (concept): A project phase focused on implementing core user interface components as independent micro-UIs within the Module Federation host shell.
- **Search Micro UI** (module): A micro-UI responsible for semantic and filtered search, displaying highlighted results with relevance scores, and respecting domain access permissions.
- **Domain Explorer Micro UI** (module): A micro-UI for listing domains with document counts, browsing documents, and viewing metadata.
- **Ingestion Status Micro UI** (module): A micro-UI providing real-time updates for ingestion jobs via WebSocket, including job progress and file upload status.
- **Shell Notifications Micro UI** (module): A micro-UI for displaying real-time toast notifications and updating a notification bell using WebSocket integration.
- **07-01-PLAN.md** (decision): The detailed execution plan document for implementing the Search Micro UI, outlining requirements, artifacts, and API contracts.
- **07-02-PLAN.md** (decision): The execution plan document for implementing the Domain Explorer Micro UI.
- **07-03-PLAN.md** (decision): The execution plan document for implementing the Ingestion Status Micro UI.
- **07-04-PLAN.md** (decision): The execution plan document for implementing the Shell Notifications Micro UI.
- **frontend/apps/search-ui** (module): The dedicated Vue.js application that will host the Search Micro UI, intended to be loaded as a Module Federation remote.
- **frontend/apps/search-ui/src/stores/search.ts** (module): A Pinia store responsible for managing the state and handling API calls related to search functionality within the Search Micro UI.
- **frontend/apps/search-ui/src/services/searchApi.ts** (module): A service module providing the API client for interacting with the Backend For Frontend (BFF) search endpoints.
- **frontend/apps/search-ui/src/components/SearchFilters.vue** (module): A Vue component implementing the user interface for filtering search results by document type, date range, and source.
- **frontend/apps/search-ui/src/components/SearchResultCard.vue** (module): A Vue component designed to display an individual search result, including highlighted text chunks and relevance scores.
- **frontend/apps/search-ui/src/types/search.ts** (module): TypeScript interfaces defining the data structures for search requests, responses, and individual search results within the application.
- **BFF /api/v1/search** (concept): The Backend For Frontend (BFF) REST API endpoint through which the Search Micro UI will make search queries.
- **Core API /api/v1/search** (concept): The Core API's REST endpoint for performing search operations, which the BFF proxies requests to.
- **SearchRequest** (concept): An interface defining the parameters for a search query, including query string, domains, search mode, result limit, and filters.
- **SearchResponse** (concept): An interface defining the structure of the response received from a search query, including the query, results array, total count, and search time.
- **SearchResult** (concept): An interface defining the structure of a single search result, encompassing chunk ID, relevance score, text content, document details, and metadata.
- **WebSocket** (concept): A communication protocol providing full-duplex communication channels over a single TCP connection, utilized for real-time updates.
- **DOM-04** (concept): A requirement specifying that search functionality must respect user's domain access permissions.
- **FE-03** (concept): A frontend requirement related to the interactive user experience, particularly relevant to the dynamic updates in the Search Micro UI.
