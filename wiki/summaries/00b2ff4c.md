# Commit 00b2ff4c

        **fix(api): add startup scripts to fix PYTHONPATH issues

Create cross-platform startup scripts that properly set PYTHONPATH before
running uvicorn. This fixes the 'ModuleNotFoundError: No module named db'
error when running the API locally.

Scripts provided:
- start.sh: Bash script for Linux/Mac/WSL
- start.bat: Batch script for Windows
- start.py: Python script that works on all platforms

Usage:
  Windows: start.bat [host] [port]
  Linux/Mac: ./start.sh
  All platforms: python start.py

Alternative: Set PYTHONPATH manually before running uvicorn:
  set PYTHONPATH=D:\02-PERSONAL\01-PROJECTS\25-KnowledgeManagement\api
  uvicorn src.main:app --reload**

        This commit adds cross-platform startup scripts (Bash, Batch, Python) to correctly set the PYTHONPATH, resolving `ModuleNotFoundError: No module named db` when running the API locally.
