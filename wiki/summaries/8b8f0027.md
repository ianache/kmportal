# Commit 8b8f0027

        **fix(api): add factory functions for vector store and embedding adapters

Add get_vector_store_adapter() and get_embedding_adapter() to adapters/__init__.py
to fix ImportError in health checks and enable proper adapter instantiation.

These factory functions allow the health check endpoint to verify connections
to ChromaDB and Gemini embedding service.**

        This commit adds factory functions, `get_vector_store_adapter()` and `get_embedding_adapter()`, to `adapters/__init__.py` to fix `ImportError`s in health checks and enable proper, configurable instantiation of vector store and embedding adapters.

        ## Changed Files
        - `api/src/adapters/__init__.py`

        ## Entities
        - **adapters/__init__.py** (module): The initialization module for the adapters package, now providing factory functions for adapter instantiation.
- **get_vector_store_adapter** (function): An asynchronous factory function that returns a configured VectorStorePort implementation, currently ChromaDBAdapter, with host and port configurable via arguments or environment variables.
- **get_embedding_adapter** (function): An asynchronous factory function that returns a configured EmbeddingPort implementation, currently GeminiAdapter, with API key and model configurable via arguments or environment variables.
- **VectorStorePort** (concept): An interface (port) defining the contract for vector store operations, implemented by concrete adapters like ChromaDBAdapter.
- **EmbeddingPort** (concept): An interface (port) defining the contract for embedding operations, implemented by concrete adapters like GeminiAdapter.
- **ChromaDBAdapter** (class): A concrete implementation of the VectorStorePort interface, used for interacting with ChromaDB.
- **GeminiAdapter** (class): A concrete implementation of the EmbeddingPort interface, used for interacting with the Gemini embedding service.
- **health checks** (concept): An API endpoint or system process responsible for verifying the operational status and connectivity of services, now utilizing the new factory functions.
