# Plan 09-01: FastMCP Server — AI Agent Integration

## Goal
Expose `search_knowledge`, `list_domains`, and `get_domain_info` as MCP tools authenticated by API Key, scoped to authorized domains, accessible at `/mcp`.

## Background
FastMCP 3.2.4 is installed (`fastmcp>=0.4.0` resolved to 3.2.4). The MCP server is mounted as an ASGI sub-app on the Core API at `/mcp`. Transport changed from deprecated SSE to Streamable HTTP.

## Implementation

### 1. MCP Server (`api/src/mcp_server/server.py`)
- `FastMCP("Knowledge Management Center")` with tool descriptions
- `@mcp.tool()` for: `search_knowledge`, `list_domains`, `get_domain_info`, `get_document_status`
- User context via `ContextVar[UserInToken]` (set by auth middleware, read by tools)
- Domain scoping: API key `allowed_domains` restricts which domains tools can access
- ASGI app: `mcp.http_app()` — Streamable HTTP transport (SSE deprecated in v3.x)

### 2. Auth Middleware (`api/src/mcp_server/auth.py`)
- `MCPAuthMiddleware(BaseHTTPMiddleware)` — validates `X-API-Key` header
- Missing key → 401 JSON response
- Invalid/expired key → 401 JSON response
- Valid key → sets `mcp_user_context` ContextVar; calls `call_next(request)`
- Health check path bypassed

### 3. Main App Integration (`api/src/main.py`)
- `mcp_app = get_mcp_app()` creates Streamable HTTP ASGI app
- `mcp_app.add_middleware(MCPAuthMiddleware)` applies API key auth to all `/mcp` requests
- `app.mount("/mcp", mcp_app)` — sub-app handles all `/mcp/*` routing
- Rate limiting: global `RateLimitMiddleware` (Redis) on main app applies to `/mcp` requests too

## Key Design Decisions
- **Stateless tools**: Each tool call opens a fresh DB session — no server-side session state needed
- **Context propagation**: `ContextVar` threads auth user from middleware to tool functions safely in async context
- **Domain scoping**: `allowed_domains = []` means unrestricted (admin); non-empty list restricts to those UUIDs
- **Rate limiting**: Handled at main app level by `RateLimitMiddleware` — no duplicate rate limiting in MCP layer

## Success Criteria
1. `GET/POST /mcp` returns 200 (MCP handshake/tool listing)
2. `search_knowledge(query="...", domain_ids=["..."])` with valid API Key returns chunks with scores
3. `list_domains()` returns only domains in API key's `domain_ids` scope
4. Request with no `X-API-Key` header → 401
5. API key scoped to Domain A cannot access Domain B (search or domain listing)
