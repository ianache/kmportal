## WebSocket Events for Notifications

The BFF broadcasts these events relevant to notifications:
```typescript
// Ingestion job events
socket.on('job:completed', {
  jobId: string,
  documentId: string,
  domainId: string,
  documentTitle: string,
  status: 'done',
  completedAt: string
});

socket.on('job:failed', {
  jobId: string,
  documentId: string,
  domainId: string,
  documentTitle: string,
  status: 'failed',
  error: string,
  failedAt: string
});

// System events (future)
socket.on('system:notification', {
  type: 'info' | 'warning' | 'error',
  title: string,
  message: string,
  action?: { label: string, route: string }
});
```
