## WebSocket Architecture (from BFF)

### WebSocket Server (Socket.IO on /ws)
```typescript
// Connection authenticated via session cookie
socket.emit('connected', { userId, email, roles });

// Subscribe to rooms
socket.emit('subscribe', { room: 'ingestion' });
socket.on('subscribed', { room });

// Ingestion events from server:
socket.on('job:created', { jobId, documentId, domainId, status });
socket.on('job:updated', { jobId, status, progress, message });
socket.on('job:completed', { jobId, documentId, status: 'done' });
socket.on('job:failed', { jobId, documentId, error, status: 'failed' });
```

### Ingestion Event Handler (bff/src/websocket/handlers/ingestion.ts)
The BFF broadcasts ingestion events to relevant users based on domain access.

## API Contracts

### Ingestion Status (GET /api/v1/ingest/{job_id})
```typescript
interface IngestionStatusResponse {
  id: string;
  document_id: string;
  domain_id: string;
  status: 'pending' | 'processing' | 'done' | 'failed';
  progress: number;              // 0-100
  started_at?: string;
  completed_at?: string;
  error_message?: string;
  created_at: string;
}
```

### Job List (GET /api/v1/ingest/jobs - may need to add this endpoint)
Query params:
- domain_id: Filter by domain
- status: Filter by status
- limit: Number of jobs to return

Response:
```typescript
interface JobListResponse {
  items: IngestionJob[];
  total: number;
}
```

### Document Upload (POST /api/v1/ingest)
Multipart form upload for triggering new ingestion jobs.
