Implement authentication state management in the shell using Pinia, integrating with the BFF's session-based auth endpoints. The shell must detect auth state on load, redirect unauthenticated users to Keycloak via BFF, and provide reactive user data to the UI.

Purpose: Enable secure access control for the knowledge management platform, ensuring only authenticated users can access domain-scoped content.
Output: Auth store, BFF client, auth guards, and type definitions.

**BFF Auth Endpoints (from bff/src/app.ts):**
- GET /auth/login - Redirects to Keycloak OAuth
- GET /auth/callback - OAuth callback, sets session
- GET /auth/logout - Clears session, redirects to Keycloak logout
- GET /auth/session - Returns { authenticated: boolean, user: { id, email, roles } }

**Session Cookie:** HttpOnly, secure, same-site. Frontend must use `credentials: 'include'`.

**BFF Port:** 3000 (configured in docker-compose)

**Existing Shell Setup:** Vue 3 + Pinia + Vue Router already initialized in main.ts with router guards placeholder.
</context>
